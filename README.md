Cálculo: sistema francés, r = TNA / 1200; cuota = (capital - pagoFinal / (1+r)^n) * r / (1-(1+r)^-n). Con tasa 0: (capital-pagoFinal)/n. Gastos al inicio no financiados. Total = entrega + n*cuota + pagoFinal + gastos. Los centavos pueden requerir ajuste de la última cuota.
